# JEV MLX 实现计划

[返回项目首页](../README.zh-CN.md)

状态：0.1 已实现。软件包、带版本的会话、localhost 服务、真实模型浏览器演示、合成测试数据和测量工具均已具备。实际完成的检查与限制记录在[结果报告](results.zh-CN.md)中；仅有源码实现或跳过的测试不能证明模型兼容性。

## 产品边界

交付一个面向 Apple Silicon 的本地决策 SDK，包含一个已验证模型、真实的本地演示和可复现的测量。首版接受英文文本与带版本的允许单步动作集合，返回允许的候选 ID 或 no-match／abstain、原始分数、候选分布、分差、模型身份、状态版本和耗时。受限 softmax 分布不是经过校准的正确概率。

首版不包含通用聊天、STT/TTS、任意生成参数、多步规划、自定义内核和训练。中文及中英混合输入应作为未来独立的评测组测试，不能根据英文结果宣称支持。

## 已完成的运行时审查

本地参考环境包含 mlx 0.31.2 和 mlx-lm 0.31.3。官方 MLX-LM 已提供模型加载／量化、缓存工厂、LRUPromptCache/PromptTrie、各缓存的 merge/extract 操作，以及分段预填充示例。实现前应重新核对选定依赖版本；复用这些能力，而非复制 FounderOS 的 provider 服务或重建框架内部实现。

首个本地兼容性目标是 Qwen3.5-9B-OptiQ-4bit。本地检查点同时具有全注意力 KV 状态和线性注意力循环／卷积状态。ArraysCache 不能像普通 KV 缓存一样裁剪。应在可变页面内容之前保留快照，在页面变化时重建其后缀。中间前缀变化会使之后所有依赖状态失效。

直接决策应调用带有官方输出头的官方模型，提取最终位置的候选 logits。不要用原始权重切片替换量化输出头。通过分词器验证的单 token 编码映射回稳定的应用候选 ID。不要将 generate(max_tokens=1) 描述为零解码：已安装的生成流程可能执行提前计算。

## 交付检查点

| 步骤 | 交付内容 | 验证方式 | 状态 |
|---|---|---|---|
| 1 | 可安装软件包、数据契约、compile_choices 与 MLXDecisionEngine.decide | 核心测试与实际本地评分 | 已实现；见结果报告 |
| 2 | DecisionSession.update_state、前缀快照与预热 | 缓存数值一致性，以及过期／重复执行／伪造结果测试 | 已实现；见结果报告 |
| 3 | CLI、localhost 服务、桌面／课程库／播放器与 DOM 适配器 | 分别记录模型决策、实际点击、回执和观察到的状态 | 已实现；见浏览器证据 |
| 4 | 冻结的公开基准、精简选项编码与生成 JSON 基线 | 保留每次尝试，按条件报告 p50/p95 与质量 | 已实现；批处理暂缓 |

多题批处理应在单题正确性验证之后进行。优先使用框架独立的批处理分支与缓存合并操作。不要给混合循环模型强加自定义的纯注意力分块掩码。批处理优化失败不应阻碍发布范围清晰的单题实验版本。

## 公开评测

从零创建数据，使用虚构名称和模拟状态；不要导出或匿名化生产数据库、录音、截图或对话轨迹。先准备开发集和独立冻结测试集，按场景类别组织。

覆盖范围：在不同对象打开／没有对象打开时理解 close-it；区分打开功能与选择其内容；筛选后的首项选择；课程库／加载中／播放器就绪状态；状态询问、否定和模糊请求；候选顺序置换；推理未完成时页面变化。提供确定性的脚本，证明过期结果不能执行。

分别报告模型原始准确率、执行精确率、可执行请求覆盖率、弃权率、格式有效率，以及宿主拒绝的提议。宿主验证拦住错误答案，不会使模型答案变正确。拒绝阈值如需拟合，应使用开发数据，并在测试前冻结。

进程／模型冷启动与权重已加载的推理分开测量。报告 KV 冷缓存、稳定状态下新话语的暖缓存，以及状态更新后的首次推理。包含模型／量化／运行时修订、硬件、提示词规模、候选数量、p50/p95、内存和失败尝试。计时必须同步 MLX 计算。不能用缓存的最终答案冒充新决策。

公平基线包括：同一模型在相同上下文与缓存条件下返回单个选项编码，以及生成结构化 JSON／工具调用的基线。串行问题与批处理问题分开比较。在实测前，不暗示比最强基线更快，也不宣传已经实现固定 100ms 目标。

## 发布

计划的首次发行包括公开 GitHub 仓库、可安装 Python 包、文档，以及带真实录制素材的本地演示。公开页面可以展示已记录的结果；实际 MLX 推理在 Apple Silicon 机器上运行。创建本地目录并不会预留包名或远程仓库名称。

模型权重保持外置。核实每个支持检查点的上游与转换版本许可证。对实际复用的第三方代码保留归属说明。本项目受 JEV 启发、独立维护，不宣称与 TypeSafe 存在关联，不使用 JEV 权重，不宣称复现 RLCD，也不在缺乏证据时宣称准确率经过校准。
